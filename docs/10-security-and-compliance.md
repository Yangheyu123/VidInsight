# VidInsight 安全与合规规范

> 本文是工程控制基线，不替代针对实际业务、合同和部署地域的专业法律意见。

## 1. 安全边界

### 允许

- 通过官方开放平台和账号主体明确授权的数据访问；
- 用户主动上传其有权处理的后台导出文件；
- 自有播放器在充分告知与同意后的行为埋点；
- 经法务与安全批准的 Computer Use：人工登录、独立会话、只读、低频、域名和动作白名单、完整审计。
- 当前述来源均不可用时，经账号主体授权、平台访问政策确认和法务/安全批准的字段级受控爬虫：固定企业出口、低频、域名/路径/字段白名单、无技术规避、完整审计和 Kill Switch。

### 禁止

- 逆向或绕过签名、验证码、访问控制、频率限制及其他技术措施；
- 自动打码、住宅代理池、指纹伪装、隐藏 WebDriver 或伪造用户行为；
- 收集账号密码、共享登录态、跨账号复用 Cookie；
- 未经授权保存、分析或对外提供视频、评论和用户信息；
- 使用采集凭证执行发布、删除、互动等写操作。

## 2. 数据分类

| 等级 | 示例 | 控制 |
|---|---|---|
| L1 公开 | 产品文档、公开聚合口径 | 常规完整性控制 |
| L2 内部 | 聚合看板、任务状态、模型成本 | 登录、工作区隔离、审计 |
| L3 机密 | 评论原文、导入文件、账号分析、用户标识 | 加密、最小权限、短保留、导出控制 |
| L4 高敏 | Client Secret、Access/Refresh Token、加密主密钥 | KMS/Vault、不可导出、严格服务身份、轮换 |

日志和监控最多保存 L2；L3/L4 默认禁止写日志。

## 3. 身份、权限与隔离

- 人员使用唯一身份，禁止共享管理员账号。
- 角色为 admin/operator/viewer，后端逐端点授权，前端隐藏按钮不能代替鉴权。
- 核心表带 `workspace_id`；跨工作区访问返回 404，并有自动化隔离测试。
- 服务身份按职责拆分：API、采集 Worker、分析 Worker 和迁移账号权限不同。
- 生产数据库禁止应用账号拥有建库、超级用户或不必要 DDL 权限。
- 高风险动作（解绑、成员变更、导出、Kill Switch）记录审计；后续可加入二次认证。

## 4. OAuth 与凭证

- 使用不可预测、单次、短时 `state`，绑定当前会话和工作区；支持时使用 PKCE。
- 回调地址为精确白名单，禁止开放重定向。
- Token 使用 KMS envelope encryption；密文、密钥版本和到期时间分离保存。
- Token 明文不返回浏览器、不进入队列参数、不写日志或错误。
- 到期前刷新采用账号级锁，失败进入明确状态；撤回授权立即停止新采集。
- Secret 至少每 90 天或供应商要求周期轮换；泄漏时立即撤销并追踪影响。

## 5. 数据最小化与隐私

- 只申请当前功能需要的 Scope，只采集明确字段。
- 评论用户 ID 使用带工作区密钥的 HMAC；分析层不保存原始用户 ID。
- 手机号、微信、精确位置、未成年人信息默认不采集；在文本中发现则脱敏或标记限制访问。
- 完播率和用户行为只在合法来源下使用；模型估算必须明确标注。
- 原始 API 响应默认 30 天，评论原文 90 天，指标快照 1 年；更长保留需记录依据。
- 支持查询、更正、删除、撤回授权和账号解绑；删除任务覆盖主库、私有文件卷、缓存和派生结果。
- 向境外 AI 服务发送数据前评估跨境要求；默认先脱敏并最小化，只发送完成任务所需片段。

## 6. Computer Use 控制

Computer Use 为独立高风险数据源，默认功能开关关闭。启用需满足：

1. 账号主体授权、平台条款和法务评审留档；
2. 独立持久化浏览器上下文，首次由用户人工扫码；
3. 固定企业出口、单账号单会话、最低频率与低并发；
4. 仅允许批准域名、页面和只读动作；禁止任意导航和下载；
5. 出现验证码、登录警告、异常跳转或 DOM 不匹配即停止；
6. 保存必要截图和动作审计，通知人工处理；
7. 可按全局、数据源和账号三级立即熔断。

### 6.1 受控爬虫控制

受控爬虫是字段级最后兜底，不能作为规避官方权限或访问限制的替代通道。启用必须满足：

1. 官方 API、Computer Use、授权导入和合同数据均不能提供明确的验收必需字段；
2. 账号/页面属于自有或已获有效授权范围，平台条款、公开访问政策和合规评审允许自动访问；
3. Policy Gate 明确 `connector_id`、域名、路径、账号、字段、目的、审批编号、频率、并发、响应大小、到期时间、owner 与 Kill Switch；
4. 固定实名企业出口，默认单域名并发 1、频率不高于 1 请求/5 秒；书面许可才可调整；
5. 尊重限流指示与适用的 robots/访问政策；使用缓存、条件请求和分页硬上限减少访问；
6. DNS 解析前后和每次重定向后校验 URL/IP，拒绝私网、环回、非 HTTP(S) 和未批准域名；
7. 遇到验证码、滑块、登录墙、挑战页、403、429 或政策变化立即熔断，不破解、不逆向签名、不伪装指纹、不轮换代理；
8. 解析器带版本、schema 指纹和 fixture；结果先进入 staging，异常进入 quarantine，人工抽检通过后才进入事实层；
9. 不采集联系方式、定位、私信、好友关系、未成年人信息等非必要个人信息；
10. 扩大账号、域名、路径、字段或频率属于新审批，不能修改旧审批记录绕过复核。

## 7. 应用与接口安全

- 全站 TLS，生产启用 HSTS、CSP、frame-ancestors、nosniff 和严格 Referrer-Policy。
- Cookie 设置 HttpOnly、Secure、SameSite；状态修改请求验证 CSRF。
- CORS 使用精确源白名单，不与凭证一起使用 `*`。
- 所有输入用 schema、长度、枚举和业务约束验证；输出做字段白名单序列化。
- 服务端获取 URL 防 SSRF：协议、DNS/IP、重定向和响应大小均验证。
- 文件上传检查扩展名、MIME、魔数、大小和恶意内容；文件卷私有，下载必须经应用鉴权。
- CSV 导出对以 `= + - @` 开头的单元格转义，避免公式注入。
- 登录、OAuth、搜索、导出、AI 和任务创建分别限流。
- 依赖和镜像持续扫描，高危漏洞阻止发布。

## 8. AI 安全

- 从视频、OCR、ASR、评论得到的文本全部视为不可信数据，不得作为系统指令执行。
- Prompt 明确分隔指令和数据；工具调用采用固定 schema 与最小白名单。
- LLM 无数据库、浏览器、文件系统和外部网络的任意权限。
- 输出经 JSON Schema、长度、枚举和内容安全校验；低置信度不生成确定性结论。
- 每次结果记录模型、版本、prompt 版本、输入引用、成本和时间。
- 建立固定评估集，评估幻觉、偏见、情感/意图准确率和建议可解释性。
- 用户界面声明 AI 结果为辅助判断，并允许反馈和重新分析。

## 9. 审计

至少记录：登录与失败、成员/角色变化、账号绑定/解绑/刷新、采集启停、手动同步、导入/导出、分析请求、预算变化、数据删除、Kill Switch 和管理配置变化。

审计事件包含操作者、动作、对象、结果、原因、时间、request ID 和最小网络上下文。审计只追加，访问本身也受审计；不得包含完整 Token、Cookie 或评论原文。

## 10. 监控与事件响应

### 10.1 触发条件

- 授权撤回、平台书面通知或账号安全提示；
- 验证码异常增加、401/403/429 激增；
- 未授权访问、跨工作区数据暴露或凭证泄漏；
- 数据被错误导出、超范围发送到模型或异常长期保留。

### 10.2 响应流程

1. 识别并分级，建立事件时间线。
2. 使用全局、来源或账号 Kill Switch 控制影响。
3. 撤销凭证、隔离 Worker、保存不可变审计证据。
4. 评估数据类别、主体、时间与接收方，通知安全/法务/管理方。
5. 修复、验证、分阶段恢复；高风险事件需批准后恢复。
6. 完成复盘、通知义务和可追踪的改进行动。

## 11. 上线安全清单

- [ ] 官方 Scope、合同和隐私告知已确认并留档。
- [ ] 工作区隔离与角色矩阵通过自动化和人工测试。
- [ ] OAuth state/PKCE、Token 加密、刷新和撤回完成测试。
- [ ] 生产 Secret 不在代码、镜像、前端、日志和 CI 产物中。
- [ ] 日志脱敏、审计、保留与删除任务已验证。
- [ ] CORS、CSRF、CSP、SSRF、上传和导出防护已验证。
- [ ] Computer Use 默认关闭；若启用，人工登录、动作白名单、验证码即停和熔断机制完整。
- [ ] 受控爬虫默认关闭；若启用，Policy Gate、审批、SSRF 防护、限流、staging/quarantine、抽样对账与 Kill Switch 全部验证。
- [ ] AI 数据最小化、输出校验、预算和评估集已启用。
- [ ] 漏洞扫描无未接受的高危问题。
- [ ] 备份恢复、Kill Switch 和事件响应完成演练。
