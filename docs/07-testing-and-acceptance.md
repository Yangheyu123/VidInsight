# VidInsight 测试与验收策略

## 1. 质量目标

测试重点不是单纯追求覆盖率，而是保护数据可信、租户隔离、外部采集幂等、指标口径和关键运营流程。

## 2. 测试分层

| 层级 | 范围 | 工具建议 | CI 要求 |
|---|---|---|---|
| 静态检查 | 格式、lint、类型、依赖与秘密扫描 | Ruff/mypy、ESLint/tsc | 每次 PR |
| 单元测试 | 指标公式、状态机、限流、格式化、组件逻辑 | pytest、Vitest | 每次 PR |
| 集成测试 | PostgreSQL、Redis、Repository、任务、迁移 | pytest + Testcontainers/Compose | 每次 PR |
| 契约测试 | OpenAPI、外部适配器、错误模型 | OpenAPI diff、录制脱敏 fixture | 每次 PR |
| 组件测试 | 表格、筛选、表单、可访问性 | Testing Library、axe | 每次 PR |
| E2E | 登录、授权模拟、采集展示、分析、导入 | Playwright | PR 核心集 + 夜间全量 |
| 性能/恢复 | 查询、并发、队列、备份恢复 | k6/Locust、恢复演练 | 发布前 |

## 3. 后端必测场景

- 相同平台账号不能在同一工作区重复绑定，不同工作区严格隔离。
- OAuth `state` 错误、过期、重放和 code 交换失败均安全终止。
- Token 刷新并发时只执行一次，失败不会覆盖仍有效凭证。
- 任务重复投递、Worker 崩溃后重投不会生成重复视频或快照。
- checkpoint 只在数据事务成功后推进。
- 429 遵循 Retry-After；401/403 转授权状态，不无限重试。
- 相邻快照负增量标记异常，不进入默认增长聚合。
- `null` 深度指标不会被转换为 0。
- 工作区 A 的 ID 不能被工作区 B 读取、修改、导出或通过时间差枚举。
- AI 输出结构不合法、部分步骤失败、取消与重试能进入正确状态。
- 上传伪造 MIME、超大文件、公式注入 CSV 和压缩炸弹被拒绝或隔离。
- 批量账号录入逐行返回结果；新增、删除、启用/停用正确写审计且停用后不再调度。
- 日/周/月边界、跨年/闰日、缺期初基线、累计值回退和平均完播率加权口径均有固定测试夹具。
- XLSX 导出继承账号、时间、周期、搜索和排序条件，包含汇总、视频明细、口径说明，公式开头文本被转义。
- 六项必需指标逐视频/逐账号覆盖率均为 100%；每个值都校验非空、范围、来源、时间与原始/导入样本一致。`model_estimate` 不能作为通过依据。
- `/metrics/coverage` 在缺少任一必需指标、诊断输入或校验过期时返回 `ready_for_acceptance=false`；全部来源和对账通过后才允许转为 true。

## 4. 前端必测场景

- 总览首次加载、后台刷新、空数据、部分失败和过期数据状态。
- 筛选条件与 URL 双向同步，前进/后退可恢复。
- 表格服务端排序、分页边界、选择跨页规则和空值显示。
- 账号重新授权、解绑确认和任务状态更新。
- 视频详情的来源徽标、估算置信区间和模型版本。
- 导入四步流程、字段错误定位和离开未提交页面提示。
- 401 自动进入登录流程；403 显示权限说明；429 不触发请求风暴。
- 键盘导航、焦点回归、屏幕阅读器名称、200% 缩放和 reduced motion。

## 5. 外部平台测试策略

- 单元与 PR 测试只使用 fake adapter 和脱敏固定响应，不依赖真实抖音网络。
- 维护官方响应 schema fixture，覆盖字段缺失、新增、null、超大计数和分页游标。
- staging 使用专用测试账号执行受限 smoke test，配额和影响可控。
- 真实凭证只存在密钥系统，CI 日志和测试报告不得输出。
- Computer Use 测试仅对批准域名与测试账号执行；验证码场景验证“停止并通知”，不自动破解。
- 受控爬虫先使用脱敏 fixture 和本地 fake server 测试 Policy Gate、限流、分页上限、解析器与 schema 指纹；staging smoke 只访问批准的单页和字段。
- 测试重定向到私网/环回、未批准域名、挑战页、403/429、超大响应、压缩炸弹、字段单位变化和结构漂移，均必须拒绝、quarantine 或熔断且不写正式快照。
- 固定样本验证来源优先级：官方值不被 Computer Use、导入、受控爬虫或模型估算静默覆盖；来源切换产生质量标记。

## 6. 指标口径测试样例

| 输入 | 期望 |
|---|---|
| 播放 0，互动 5 | 互动率为 null，界面显示 `—` |
| 当前播放 90，前次 100 | 增量标记 anomaly，不显示 -10 增长 |
| 两个来源同时间：官方与估算 | 最新展示优先官方，估算保留但不覆盖 |
| 时间范围跨上海自然日 | API 按 `Asia/Shanghai` 边界聚合并返回 UTC 范围 |
| 无视频 | 平均播放量为 null，不除零 |

建议对指标公式使用属性测试：计数非负、来源优先级稳定、聚合总值等于成员值之和（排除质量异常后）。

### 6.1 五类诊断验收样例

| 场景 | 预期规则 | 预期建议方向 |
|---|---|---|
| 完播率低 | `LOW_COMPLETION` | 钩子/节奏 |
| 播放高、互动低 | `HIGH_PLAY_LOW_ENGAGEMENT` | 互动设计 |
| 播放低、完播高 | `LOW_PLAY_HIGH_COMPLETION` | 封面标题/选题曝光 |
| 播放和完播都低 | `LOW_PLAY_LOW_COMPLETION` | 选题脚本/受众匹配 |
| 播放高、视频级涨粉低 | `HIGH_PLAY_LOW_FOLLOW` | 人设/关注引导 |
| 完播率或涨粉归因缺失 | 不触发依赖字段的确定性规则 | 显示数据不足及缺失来源 |

规则测试固定阈值版本与基线样本，分别验证边界等于阈值、样本不足退化、LLM 超时回退模板以及证据字段完整。

## 7. 性能验收数据集

MVP 基准数据：100 个账号、10,000 个视频、2,000,000 条指标快照、500,000 条评论。至少测试：

- 总览 7/30/90 天聚合；
- 账号详情 90 天趋势；
- 视频列表多条件筛选与排序；
- 50 个并发查看用户；
- 20 个并行采集任务和 5 个分析任务；
- 10 万行导入与导出。

目标：常用看板查询 P95 < 3 秒；普通应用 API P95 < 500ms；错误率 < 1%；任务积压可在容量设计时间内消化。

## 8. 安全测试

- 水平/垂直越权、ID 枚举与导出越权；
- Session 固定、CSRF、CORS、OAuth 重放与开放重定向；
- SQL/全文检索注入、XSS、CSV 公式注入、SSRF；
- 日志、错误、OpenAPI 与监控中的秘密泄漏；
- 文件解析、下载鉴权、路径穿越和私有文件卷权限；
- 受控爬虫 SSRF、重定向复检、Policy Gate 越权、配置范围扩大与 Kill Switch；
- 依赖漏洞与容器镜像扫描。

## 9. CI 质量门禁

合并前必须通过：

1. 格式、lint、类型检查无错误；
2. 单元与集成测试通过；
3. 新增/变更核心逻辑有对应测试；
4. OpenAPI 无未经批准的破坏性变更；
5. 数据库可从空库迁移到 head；
6. 高危依赖漏洞和秘密扫描为零；
7. 前端关键页面 axe 无严重问题；
8. 构建产物和容器镜像可生成。

覆盖率参考门槛：整体行覆盖率 ≥ 80%，鉴权、隔离、指标公式、状态机与幂等模块分支覆盖率 ≥ 90%。覆盖率下降需要 PR 明确解释。

## 10. 发布验收

- 产品按 PRD 的全部 MVP 业务标准验收。
- 测试完成关键 E2E、浏览器兼容和回归。
- 运维完成迁移预演、监控告警、备份和回滚验证。
- 安全完成权限矩阵、凭证与审计抽查。
- 任何已启用的 Computer Use/受控爬虫均完成审批有效性、dry-run、抽样对账、异常熔断和停机演练。
- staging 连续 72 小时无阻塞问题，再进行小范围灰度。

## 11. 原始需求验收用例

| ID | 验收对象 | 通过标准 |
|---|---|---|
| ACC-01 | 批量录入 | 100 行以内逐行返回；合法账号成功、重复/非法行报错且不回滚其他行 |
| ACC-02 | 新增、删除、启用/禁用 | 状态、权限和审计正确；停用/删除立即停止新采集任务 |
| ACC-03 | 账号列表 | 始终展示账号名称、账号 ID、授权状态和最后同步时间 |
| SYNC-01 | 自动定时同步 | 六项必需指标按调度写入，任务和来源可追溯 |
| SYNC-02 | 手动刷新 | 返回 202 与任务 ID；结束后仅刷新受影响账号/视频数据 |
| SYNC-03 | 单条视频字段 | 播放、点赞、评论、转发、完播率均非空、范围正确、有非模型来源 |
| SYNC-04 | 新增粉丝 | 账号期初/期末可靠快照可计算增量，周期口径正确 |
| SYNC-05 | 历史回溯 | 同一视频多次采集产生多条快照，旧记录保持不变 |
| STAT-01 | 日/周/月 | `Asia/Shanghai` 边界、跨年/闰日和等长环比均正确 |
| STAT-02 | 周期汇总 | 总播放、总点赞、总涨粉、总评论、总转发、平均完播率与固定快照夹具一致 |
| STAT-03 | 明细与筛选 | 账号、时间、指标排序、分页和 URL 恢复一致 |
| EXP-01 | Excel 导出 | XLSX 含“汇总、视频明细、口径说明”，数据与当前筛选完全一致 |
| DIA-01～05 | 五类诊断 | 五个固定样本分别命中规定规则和规定建议方向，证据字段完整 |
| UI-01 | 矩阵大盘 | 六项核心指标、趋势和账号/视频排行完整展示 |
| UI-02 | 单账号详情 | 趋势曲线、作品列表、完整指标、诊断结论和来源完整展示 |
| UI-03 | 内部 Web | 未登录不可访问；viewer/operator/admin 权限与页面操作一致 |

任何一项失败，或 `/metrics/coverage` 不为 `ready_for_acceptance=true`，均不得标记为本期需求完成。
