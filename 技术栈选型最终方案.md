## 二、前端选型详解

### 2.1 技术选型清单

| 技术 | 用途 | 选型理由 |
|------|------|---------|
| **React 18** | UI 框架 | 生态最成熟、组件化、Hooks 简洁 |
| **TypeScript** | 类型系统 | 接口数据有类型定义，减少联调 bug |
| **Vite** | 构建工具 | 秒级热更新，开发体验远超 CRA |
| **Tailwind CSS 4** | 样式框架 | 2026 最新版，零配置，原子化 CSS，改样式不用切文件 |
| **shadcn/ui** | UI 组件 | 不是组件库，是**可复制的组件代码**，完全归你所有，样式随便改，不像 Element Plus 那样受限 |
| **TanStack Query** | 服务端状态管理 | 替代 Redux，自动管理 API 请求、缓存、loading、错误状态 |
| **Recharts** | 图表库 | 基于 React 组件声明式写图表，跟 Tailwind 风格一致 |
| **React Router 6** | 路由 | 标准路由方案 |
| **dayjs** | 日期处理 | 轻量，2KB 替代 moment.js |

### 2.2 为什么不用 Element Plus / Vue3

| 对比 | Vue3 + Element Plus | React + Tailwind + shadcn/ui |
|:----:|:-------------------:|:----------------------------:|
| **样式风格** | 传统后台管理系统风格（表格+表单+对话框） | 现代 SaaS 风格（简洁、留白、卡片式） |
| **改样式** | 需要覆盖 Element Plus 的样式，麻烦 | Tailwind 直接在元素上写类名，想改就改 |
| **组件控制权** | 组件库维护，你只能通过 props 改 | 代码在你项目里，随便改底层 |
| **TypeScript 支持** | 一般 | 一流 |
| **生态系统** | Vue 生态 | React 生态更大，组件库选择更多 |
| **学习曲线** | 低（你会 Vue） | 中（但你愿意学） |

### 2.3 shadcn/ui 说明

不是传统组件库，而是**让你把组件源码复制到项目的工具**：

```
npm install element-plus      → 安装黑盒组件，只能通过 props 定制
npx shadcn add card           → 把 card 组件的源码复制到你的项目里
                                → 完全归你所有，源码随便改
                                → 样式用 Tailwind，跟你项目风格一致
```

**效果：** 页面看起来像 Vercel / Linear / Notion 那种现代风格，不是传统后台的"土味"。

## 三、后端选型详解

### 3.1 技术选型清单

| 技术 | 用途 | 选型理由 |
|------|------|---------|
| **FastAPI** | Web 框架 | 异步原生、自动生成 OpenAPI 文档、Python AI 生态无缝对接 |
| **SQLAlchemy 2.0** | ORM | 异步支持、类型安全、最成熟的 Python ORM |
| **PostgreSQL** | 数据库 | 功能最全的开源数据库，支持 JSONB、全文检索 |
| **Celery + Redis** | 定时任务 + 消息队列 | 采集任务异步执行，不阻塞 API 响应 |
| **openai / anthropic SDK** | AI 分析 | 调大模型 API 分析视频内容和评论 |
| **requests / httpx** | HTTP 客户端 | 调抖音开放平台 API |
| **Alembic** | 数据库迁移 | 版本化管理数据库表结构 |

### 3.2 为什么不用 Spring Boot

| 对比 | Spring Boot + Java | FastAPI + Python |
|:----:|:-----------------:|:----------------:|
| **AI 生态** | 大模型 SDK 能用但体验差 | Python 原生生态，SDK 最全 |
| **数据处理** | 没有 Pandas 等价物 | Pandas 一行 = Java 20 行 |
| **代码量** | 同样功能代码量多 3-5 倍 | 极简，同样功能代码量少 |
| **开发速度** | 慢（编译、配置、依赖注入） | 快（写即运行） |
| **异步** | 配置复杂 | 原生 async/await |
| **API 文档** | 需要 SpringDoc 配置 | 自动生成 Swagger UI |
| **你的掌握度** | 熟练 | 略懂，但 AI 能帮你写 |

## 四、前后端协作方式

### 4.1 API 通信

```
前端（React）                    后端（FastAPI）
    │                                │
    │  GET /api/dashboard/overview   │
    │───────────────────────────────▶│
    │                                │ 查询数据库
    │                                │ 聚合计算
    │  { account_count, video_count, │
    │    total_plays, total_likes }  │
    │◀───────────────────────────────│
    │                                │
    │  GET /api/dashboard/trends     │
    │───────────────────────────────▶│
    │                                │
    │  [{ date, plays, likes }, ...] │
    │◀───────────────────────────────│
    │                                │
    │  前端 TanStack Query 自动管理： │
    │  • 缓存数据避免重复请求         │
    │  • 自动刷新（配置 refetchInterval）│
    │  • 加载状态（isLoading）        │
    │  • 错误处理（isError）          │
    │  • 乐观更新                    │
```

### 4.2 接口规范

```typescript
// 前端 TypeScript 类型定义（自动同步后端 Pydantic 模型）
interface Overview {
  account_count: number
  video_count: number
  total_plays: number
  total_likes: number
  avg_plays: number
}

interface TrendPoint {
  date: string
  plays: number
  likes: number
}

interface VideoItem {
  id: string
  title: string
  play_count: number
  like_count: number
  comment_count: number
  share_count: number
  account_name: string
}

// TanStack Query 调用示例
import { useQuery } from "@tanstack/react-query"

const useOverview = () => useQuery<Overview>({
  queryKey: ["overview"],
  queryFn: () => fetch("/api/dashboard/overview").then(r => r.json()),
  refetchInterval: 60_000,  // 自动刷新
})
```

## 六、部署方案

### docker-compose.yml

```yaml
version: "3.8"
services:
  postgres:
    image: postgres:16
    environment:
      POSTGRES_DB: douyin
      POSTGRES_USER: douyin
      POSTGRES_PASSWORD: ${DB_PASSWORD}
    volumes:
      - pgdata:/var/lib/postgresql/data
    ports:
      - "5432:5432"

  redis:
    image: redis:7-alpine
    ports:
      - "6379:6379"

  backend:
    build: ./backend
    environment:
      DATABASE_URL: postgresql+asyncpg://douyin:${DB_PASSWORD}@postgres/douyin
      REDIS_URL: redis://redis:6379
      DOUYIN_CLIENT_KEY: ${DOUYIN_CLIENT_KEY}
      DOUYIN_CLIENT_SECRET: ${DOUYIN_CLIENT_SECRET}
      OPENAI_API_KEY: ${OPENAI_API_KEY}
    ports:
      - "8000:8000"
    depends_on:
      - postgres
      - redis

  frontend:
    build: ./frontend
    ports:
      - "80:80"
    depends_on:
      - backend

volumes:
  pgdata:
```

## 七、开发环境快速启动

```bash
# 后端
cd backend
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
# → http://localhost:8000/docs  (Swagger UI)

# 前端
cd frontend
npm create vite@latest . -- --template react-ts
npm install
npm run dev
# → http://localhost:5173
```
